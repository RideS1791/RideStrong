# RideStrong — Cycling Strength Coach

A lightweight progressive web app for the A/B dumbbell strength plan, Zwift planning and workout tracking.

## Install on iPhone
1. Open the published GitHub Pages URL in **Safari** on your iPhone.
2. Tap **Share** → **Add to Home Screen** → **Add**.

## Features
- Rolling strength pattern: Workout A, Workout B, rest, repeat.
- Dumbbell exercise lists with demonstration-search links.
- 40-second work / 20-second rest interval timer.
- Editable suggested Zwift slots.
- Local workout log and progress counts.
- Apple Calendar .ics export.

## Notes
- Workout logs and settings are stored locally in the browser on this device; there is no cloud account or sync.
- Video links open YouTube search results.
- The default strength-cycle start date is 2 November 2026 and can be changed in Settings.
- Adjust Zwift intensity and duration around your actual training load and recovery.
